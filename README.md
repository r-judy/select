# 🎯 발표자 뽑기 프로그램 (Presenter Picker)

제시해주신 파이썬 코드를 기반으로 제작된 발표자 뽑기 프로그램입니다.
콘솔(터미널) 환경과 브라우저(웹 GUI) 환경 두 가지 모두 제공됩니다.

---

## 📁 구성 파일

1. **`main.py` (개선된 파이썬 프로그램)**
   - 입력값 검증(문자 입력 시 프로그램 비정상 종료 방지)
   - 제외 번호 예외 처리(빈 값 엔터 시 제외 번호 없이 진행)
   - **3번 종료 옵션** 추가 (프로그램을 안전하게 종료 가능)
   - 정렬된 당첨 번호 깔끔하게 출력

2. **`index.html` (웹 브라우저용 인터랙티브 프로그램 - 강력 추천 ✨)**
   - 별도의 설치나 파이썬 실행 없이 **파일을 더블 클릭**하면 크롬/엣지 브라우저에서 바로 실행
   - 🎲 두구두구 셔플 롤링 애니메이션 및 🎉 축하 팡파레 효과음, 폭죽(컨페티) 연출
   - 번호 칩 클릭을 통한 간편한 제외/포함 토글 기능
   - 이전 추첨 기록(히스토리) 확인 기능

3. **`original_picker.py` (원본 코드)**
   - 질문해주신 원본 파이썬 코드 그대로 보존

4. **`실행하기.bat`**
   - 더블 클릭하여 웹 화면 실행 또는 파이썬 실행을 손쉽게 선택할 수 있는 윈도우 실행 파일

---

## 🚀 실행 방법

### 방법 1. 웹 화면으로 바로 실행 (가장 추천)
- 폴더에 있는 **`index.html`** 파일을 더블 클릭하여 열거나, **`실행하기.bat`**에서 `1`을 선택합니다.

### 방법 2. 파이썬 콘솔로 실행
터미널 또는 명령 프롬프트(cmd)에서 다음 명령어 실행:
```bash
python main.py
```
또는 원본 코드 실행:
```bash
python original_picker.py
```
